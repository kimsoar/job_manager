현재 진행 중인 프로젝트의 전체 구조와 구현 상태를 분석해줘.

목표: 코드를 수정하지 않고, 기존 프로젝트를 정확하게 이해하기 위한 기술 분석 보고서를 작성한다.

분석 항목

1. 프로젝트 디렉터리 구조와 주요 모듈의 역할
2. 프런트엔드와 백엔드의 아키텍처 및 데이터 흐름
3. 주요 API, 서비스, 저장소 및 외부 시스템 간의 호출 관계
4. 핵심 비즈니스 로직과 주요 실행 흐름
5. 설정, 인증, 예외 처리, 로깅 및 테스트 구조
6. 중복 코드, 복잡한 의존성, 잠재적인 버그와 기술 부채
7. 개선이 필요한 항목과 우선순위

분석 원칙

* 실제 소스 코드와 설정 파일을 근거로 분석한다.
* 확인된 사실과 추정 사항을 구분한다.
* 분석하지 않은 파일이나 기능을 분석 완료했다고 주장하지 않는다.
* 기존 파일을 수정하거나 삭제하지 않는다.
* 비밀 키, 토큰, 비밀번호 등 민감한 값을 보고서에 노출하지 않는다.

최종 산출물

* 전체 아키텍처 요약
* 주요 모듈별 역할 및 의존성
* 핵심 데이터 흐름
* 문제점과 개선 후보 목록
* 추가로 확인해야 할 사항

우선 프로젝트를 탐색하고 분석 범위를 정한 뒤, 분석을 진행해줘. 코드 수정은 하지 마.
